components/ (Общие / "Глупые" компоненты) Здесь живут "тупые" элементы интерфейса (UI-kit). Кнопки (Button), поля ввода (Input), модальные окна (Modal). Они "глупые", потому что ничего не знают про твой бэкенд, про авторизацию или про файлы. Они получают данные снаружи (через props) и просто красиво их рисуют. Это позволяет переиспользовать одну и ту же кнопку Button на всех страницах.
