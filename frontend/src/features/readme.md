features/ (Бизнес-логика / "Умные" компоненты) Здесь лежит самое интересное — логика твоего приложения, сгруппированная по смыслу (фичам). Например, features/auth/ (авторизация). В ней будет компонент LoginForm, который уже знает, что при нажатии на кнопку нужно взять логин и пароль и отправить их на сервер. Или features/files/ — там будет логика загрузки файла в твой Django.
