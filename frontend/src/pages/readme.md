pages/ (Страницы) Тут лежат компоненты, которые отвечают за целый "экран" пользователя. Одна страница = один URL в браузере. Например: если в браузере /login, показываем LoginPage.tsx. Если /storage — StoragePage.tsx. Страницы обычно не содержат сложной логики и верстки, они просто собирают другие компоненты как конструктор Lego.
