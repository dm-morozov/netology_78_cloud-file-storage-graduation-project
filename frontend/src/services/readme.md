services/ (или api/) Твой фронтенд должен общаться с бэкендом (Django). Если ты будешь писать URL-адреса запросов прямо внутри кнопок, то при изменении адреса сервера тебе придется переписывать половину проекта. В services/ мы создадим единый клиент (на базе библиотеки Axios), где укажем базовый URL и настроим передачу CSRF-токенов. Если бэкенд переедет, мы поменяем ссылку только в одном месте.
