store/ (Состояние приложения) Для работы с Redux. В React компоненты часто хотят знать глобальные вещи: например, авторизован ли сейчас пользователь? Администратор ли он? Передавать эти данные от компонента к компоненту вручную (через цепочку props) очень больно. store — это глобальная переменная (склад), откуда любой компонент может узнать, кто сейчас вошел в систему.
